The problem

Nobody can see the batch.

Every strip of medicine carries a batch number and an expiry date. That data exists for about four seconds — long enough to be written onto a paper bill — and is then never queryable again by anyone in the chain.

Printed on the carton

The manufacturer knows the batch exactly.

Copied to a paper bill

Written once, by hand, into a register nobody reads.

Gone

No shop can answer: what expires next month?

This is the thesis of the whole company. Slow down on “nobody can see the batch” — everything in the rest of the deck is a consequence of it. If an investor only remembers one sentence, make it this one.
